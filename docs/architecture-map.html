系统架构图

这一层展示运行时对象如何组合：前端是操作门面，FastAPI 是 API 和状态注入层，摄像头检测与后台任务长期运行。

默认是单节点边缘部署：SQLite 和文件目录都在本机。
单节点运行拓扑 python -m argus --config configs/default.yaml
用户与浏览器
Vue SPA主路由、模型页、系统页、回放页。
API ClientAxios 请求 /api/*。
WebSocket Client订阅 health、alerts、tasks、degradation 等主题。
Video Player优先使用 go2rtc WebRTC/MSE/HLS，失败时回退。
FastAPI Dashboard
REST API摄像头、告警、模型、训练、回放、系统管理。
ConnectionManagerjanus 队列桥接同步线程和异步 WebSocket。
ASGI Middleware安全头、限流、认证；避免 BaseHTTPMiddleware。
app.state注入数据库、CameraManager、go2rtc、任务、降级、回放存储。
实时检测

DetectionPipeline区域、预筛、YOLO、异常、Simplex、告警分级。
go2rtc视频代理；USB 摄像头由它独占并转 RTSP。

Audit & Backup审计日志、数据库和配置备份。

核心数据流图

摄像头帧进入后，检测链先降吞吐压力，再做主异常检测和安全通道校验，最终进入告警、存储和回放链路。

Simplex、健康检查、漂移检测、环形缓冲是默认运行路径的一部分。
实时检测与告警路径 每路摄像头一个 Pipeline / Runner
1

Camera Source

RTSP、USB、视频文件。USB 默认先交给 go2rtc 接管。

2

CameraCapture

采集、重连、帧率控制、状态统计。

3

Zone Mask

应用 include / exclude 区域，多区域独立评估。

4

MOG2 Prefilter

跳过无变化帧；heartbeat 与异常锁定可绕过预筛。

5

YOLO Filter

人员或目标类别过滤，支持 tracking 和 SAHI。

6

Anomaly Detector

PatchCore、EfficientAD、Dinomaly 等异常模型路径。

7

Simplex Safety

低依赖传统 CV 安全通道，作为主模型旁路信号。

8

AlertGrader

融合分数、证据、区域优先级和传感器 multiplier。

AlertDispatcher保存快照和热力图，写入 alerts 表，推送含证据状态的 WebSocket。
Alert Ring Buffer触发后先固化前后帧，再生成回放录像和 alert_recordings 记录。
EventBus发布 FrameAnalyzed / AlertRaised，驱动主动学习和诊断。

训练闭环图

训练不是同步请求内完成，而是从采样、反馈、标注进入训练作业队列，再通过模型注册和发布管线影响线上检测。

训练完成的候选模型不会直接上线，需要经过模型发布阶段。
Baseline / Labeling / Feedback 到 Production Model 异步后台任务 + 发布管线
Data

Baseline Versions

基线图片按 camera、zone、version 管理，支持 Draft、Verified、Active、Retired 状态。

Samples

Labeling & Feedback

主动学习、误报反馈和人工标注进入标注队列或反馈队列。

Jobs

Training Jobs

API 创建任务，确认后由调度器定期消费 queued 作业。

Registry

Model Registry

记录模型版本、hash、路径、阈值、backbone 引用和发布阶段。

Release

Release Pipeline

Candidate 经 Shadow、Canary、Production 流转；Shadow 旁路评分不告警，Canary 成为该摄像头主模型。

stage transition 提交后由 CameraManager 刷新 shadow runner、canary primary routing 和 production 热载；Production Model 生效后，新的告警、反馈和不确定样本继续进入下一轮训练闭环。
